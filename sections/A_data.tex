\section{Data, software and reproducibility}\label{app:data}
\paragraph{Sequence data.} The coding sequences are example files distributed with public software and read without modification. The \emph{E.\,coli} K-12 MG1655, \emph{S.\,aureus} NCTC 8325, \emph{S.\,argenteus} and \emph{S.\,agnetis} files are the nucleotide FASTA examples of the CodonU package; the \emph{C.\,simulans} PES1 record is the GenBank file distributed with the codoff package; the \emph{A.\,thaliana} plastid record (NC\_000932) is from the Biopython test suite \citep{cock2009}; the list of highly expressed \emph{E.\,coli} genes is the example file of the freqgen package. SHA-256 sums of the files as used are in \texttt{data/CHECKSUMS.txt} of the archive. The accessions of \cref{tab:filters} are those in the file headers.
\paragraph{Corpus and inventories.} SemCor is read through NLTK \citep{bird2009} from the \texttt{semcor} and \texttt{wordnet} packages (WordNet~3.0). Documents whose path begins with \texttt{brown1} or \texttt{brown2} are used; \texttt{brownv} (verbs only) is not. The wordnets of other languages are the tab files of the \texttt{omw-1.4} package \citep{bond2013}; only lines of type \texttt{lemma} are used.
\paragraph{Software.} Python with NumPy, SciPy, pandas and Biopython; LaTeX with pgfplots. The versions used are in \texttt{data/ENVIRONMENT.txt}. Random generators are seeded in each script; the seed of every experiment is in its script.

## Abstract

Shannon set the meaning of messages aside as irrelevant to the engineering problem. This paper restores it as bookkeeping.

For a source that pairs what is meant, $W$, with what is said, $X$, the joint entropy divides exactly into three non-negative parts:
1. **Conveyed Information:** $I(W;X)$, the mutual information between meaning and form.
2. **Latitude:** $\mathrm{Lat} = H(X \mid W)$, the freedom the speaker retains to choose the form once the meaning is fixed (synonymy).
3. **Doubt:** $\mathrm{Dbt} = H(W \mid X)$, the ambiguity the listener cannot resolve from the form alone.

The identities follow from the chain rule; the operational and empirical use made of them is the contribution:
- **Operational Steganography:** In an idealized model with a shared key, latitude is the exact channel capacity at which a hidden message can be embedded into the form of an unambiguous source without altering meaning or surface statistics.
- **Genetic Code Measurements:** Across six sequenced genomes where the meaning map is the genetic code and the doubt is zero, latitude is 1.235–1.501 bits per codon. Synonymous codon choice carries 88.5% of the information that identifies the genome of a codon and 90.2% of the information separating highly expressed *E. coli* genes from the rest; held-out genes reproduce these information values to within 0.003 bits; and 90,127 bits were hidden in 240 real genes without changing the encoded amino-acid sequence of any of them.
- **English Corpus (SemCor & WordNet):** In natural language, the balance between latitude and doubt depends on whether forms are counted as lemmas or inflected surface tokens: on the well-attested core of SemCor, doubt exceeds latitude for lemmas by 0.44 bits per word, but not for inflected words, and among 22 wordnets, latitude exceeds doubt in 12.

Every number, table, and figure in the paper is generated by the accompanying codebase and validated against closed-form numerical identities.

## Reproducing the Results

### 1. Requirements

- **Python 3.10+** (Tested on Python 3.12 and 3.13)
- Required packages: `numpy`, `scipy`, `pandas`, `biopython`, `nltk`
- **TeX Live / MiKTeX** (optional, to build the paper): `pgfplots`, `booktabs`, `microtype`, `mathpazo`, `natbib`, `cleveref`, `etoolbox`, `needspace`

### 2. Environment Setup

#### Using Python venv:
```bash
# Clone the repository
git clone https://github.com/4t1a/Latitude-Doubt.git
cd Latitude-Doubt

# Create and activate a virtual environment
python -m venv .venv
source .venv/bin/activate        # On Windows: .venv\Scripts\Activate.ps1

# Install dependencies
pip install -r requirements.txt
```

#### Using Conda:
```bash
conda env create -f environment.yml
conda activate latitude-and-doubt
```

#### Using Docker:
```bash
docker build -t latitude-and-doubt .
docker run --rm -v "$(pwd)/data_out:/workspace/data_out" latitude-and-doubt
```

### 3. Running the Pipeline

You can rerun the entire experimental pipeline from scratch:

**Linux / macOS (via Make or Bash):**
```bash
make all          # Fetches data, runs experiments (~25 min), regenerates tables, builds PDF
# or
./run_all.sh      # Reruns all Python experiments without recompiling LaTeX
# or
make pdf          # Recompiles the PDF directly from shipped results
```

**Windows (via PowerShell or CMD):**
```powershell
# PowerShell
.\run_all.ps1

# Command Prompt
run_all.bat
```

### 4. Verification and Automated Tests

To immediately verify the mathematical identities (ledger partitioning, belief sufficiency, leakage, and bounds) across 100,000 randomized distributions:

```bash
# Theoretical identity verification (numerical precision < 1e-14)
python code/verification.py

# Pytest suite
pytest tests/
```

### 5. Third-Party Data & Integrity

`code/fetch_data.py` downloads raw data from authoritative public sources (CodonU, codoff, freqgen, Biopython tests, and NLTK packages `semcor`, `wordnet`, and `omw-1.4`). 

The SHA-256 cryptographic digest of every downloaded file is recorded in [`data/CHECKSUMS.txt`](data/CHECKSUMS.txt). The raw upstream files are not redistributed in this repository; compare the checksums if upstream data sources update.

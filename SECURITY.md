# Security Policy

## Supported Versions

This is a scientific research and reproducibility codebase. Maintenance and verification are provided for the primary release version:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

---

## Reporting a Vulnerability

If you identify a security issue (e.g., in data handling, dependency supply chain, or network fetching scripts in `code/fetch_data.py`), please do not disclose it in a public GitHub issue.

Instead, please report it privately to:
* **Contact:** Moustafa Mahmoud Atta
* **Email:** [m.m.atta@outlook.com](mailto:m.m.atta@outlook.com)

Please include:
1. Description of the issue and affected components.
2. Steps to reproduce or proof of concept.
3. Suggested fix or mitigation, if known.

Reports will be acknowledged promptly and addressed in an upcoming patch release.
